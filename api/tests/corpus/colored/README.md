# Colored fixtures

Three colored (symmetric) instances of the Model Checking Contest 2026 inputs
(<https://mcc.lip6.fr/2026/>), unchanged, used by the tests of the colored summary. With the
`PGCD-COL-D04N050` instance of `../mcc/` they cover enumerations, products, the dot sort, guards,
successor and subtraction. The models belong to their authors, named in the contest's model forms
(`https://mcc.lip6.fr/2026/pdf/<Family>-form.pdf`); they are redistributed here only as fixtures.

`guarded.pnml` is made by hand: one guard with `and`, `not`, inequality and a comparison with a
successor, a sum of multisets and a weighted multiplicity.
